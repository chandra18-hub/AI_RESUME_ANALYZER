# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer that helps job seekers evaluate and improve their resumes. The application analyzes uploaded resumes, identifies missing skills, provides improvement suggestions, and calculates an ATS (Applicant Tracking System) compatibility score.

---

## 📌 Features

- 📄 Upload Resume (PDF/DOCX)
- 🤖 AI-Based Resume Analysis
- 📊 ATS Score Calculation
- 📝 Skill Extraction
- 💼 Job Role Matching
- 📈 Resume Strength Analysis
- 💡 Personalized Improvement Suggestions
- 🎯 Resume Keyword Analysis
- 📱 Responsive User Interface
